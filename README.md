# Smart Kitchen Gas & Fire Alert System — Pitch Deck

Group 4 IoT final project slides (Next.js App Router, TypeScript, Tailwind).

## Run

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

- **Next / previous:** Right/Left arrow, Space, or click (click the left edge to go back)
- **Fullscreen:** press `F`
- Slide number is shown bottom right; the URL hash (`#3`) keeps your place on refresh.

## Export to PDF

Open http://localhost:3000/print in Chrome, press Cmd/Ctrl+P, choose **Save as PDF**, set Margins to **None**, tick **Background graphics**, and save: you get one 16:9 slide per page.

Images live in `public/images/`. Slide content is in `components/slides.tsx`.
